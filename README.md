# CodeAlpha_EDA

## Exploratory Data Analysis on Supermarket Sales

### Project Overview
This project explores supermarket sales data using Python. The goal is to understand sales patterns, customer ratings, payment methods, and customer behavior.

### Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Analysis Performed
- Examined the dataset structure and data types.
- Checked for missing values and duplicate records.
- Analyzed sales by product line and city.
- Explored customer ratings and payment methods.
- Compared monthly sales.
- Analyzed sales and average transaction values by customer type.
- Created charts to visualize the results.

### Key Findings
- Food and beverages had the highest total sales among product lines.
- January had the highest total sales among the three months analyzed.
- E-wallet was the most frequently used payment method, closely followed by cash.
- Members had a slightly higher average transaction value than normal customers.

### Dataset
The project uses the `supermarket_sales.csv` dataset stored in the `data` folder.

### How to Run
1. Install Python.
2. Install the required libraries:
   `pip install pandas numpy matplotlib seaborn`
3. Run the script:
   `python eda.py`
