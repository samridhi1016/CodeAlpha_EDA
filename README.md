# CodeAlpha_EDA

## Exploratory Data Analysis on Supermarket Sales

### Project Overview
This is a beginner-level data analysis project completed as part of the CodeAlpha Data Analytics Virtual Internship. It explores supermarket sales data using Python.

### Tools Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

### Analysis Performed
- Dataset overview and data quality checks
- Sales by product line and city
- Customer rating analysis
- Payment method analysis
- Monthly sales analysis
- Sales by customer type
- Average transaction value comparison

### Key Findings
- Food and beverages had the highest total sales among product lines.
- January had the highest total sales among the three months analyzed.
- E-wallet was the most frequently used payment method, closely followed by cash.
- Members had a slightly higher average transaction value than normal customers.

### Dataset
The dataset is stored in `data/supermarket_sales.csv`.

### How to Run
Install the required libraries:

`pip install pandas numpy matplotlib seaborn`

Then run:

`python eda.py`
